# じしゅ勉タイマー（Android）

自主学習の時間を子ども自身が管理するためのAndroidネイティブアプリです。2人の子ども（名前は自由に設定可）に対応し、曜日ごとに目標学習時間を設定できます。

## 基本仕様

- **学習の計測**：自動検知はせず、子どもが「勉強をはじめる／やめる」ボタンを押して自己申告で計測します。ボタンを押して終了すると合図音が鳴ります。
- **バックグラウンド計測**：開始時刻（絶対タイムスタンプ）を保存し、都度「今との差」を計算する方式なので、アプリを閉じていても、次に開いたときに正しい経過時間へ復元されます（常駐サービス不要）。
- **アラーム**：曜日ごとの目標時間が未達成のまま「勉強していない」状態が続くと、子どもごとに設定した間隔A分ごとに繰り返し通知（アラーム）が鳴ります。勉強ボタンがON（勉強中）のときは鳴りません。アプリを閉じていてもAndroidの`AlarmManager`で正確に鳴らします。
- **1日の区切り**：深夜0時。目標を達成した日はそれ以降アラームは鳴りませんが、勉強ボタンを押せば追加の学習時間も記録され続けます。
- **記録・CSV出力**：日ごとの学習時間・目標・達成有無を端末内に保存し、共有シート（メール添付など）でCSVとして書き出せます。
- **目標設定**：曜日ごとの目標時間、子どもごとのアラーム間隔A、名前は子ども自身がアプリ内の「目標・設定」画面から変更できます。
- **保存先**：端末内のみ（Room/SQLite）。クラウド同期はありません。

## プロジェクト構成

```
android-app/
  app/src/main/java/com/familystudytimer/app/
    MainActivity.kt          画面遷移・権限リクエストの起点
    StudyTimerApp.kt         Applicationクラス（DB/Repository/通知チャンネルの初期化）
    data/                    Room エンティティ・DAO・StudyRepository（中心となるビジネスロジック）
    alarm/                   AlarmManager 予約、通知、リブート/深夜0時ハンドリング
    ui/                      Jetpack Compose 画面（初期設定・権限案内・ホーム・設定・履歴）
    csv/                     CSVエクスポート
    util/                    日時ユーティリティ、効果音
```

## ビルド方法（重要）

**この開発コンテナには Android SDK が無く、また Google の Maven リポジトリ（dl.google.com）への
アウトバウンド通信がプロキシでブロックされているため、この環境内では `./gradlew assembleDebug` の
ようなビルドを最後まで通すことができません。**（Android Gradle Plugin 自体が Google のリポジトリに
しか無いため。Gradle Wrapper 自体は正常に動作することは確認済みです。）

お手元で以下の手順でビルドしてください。

1. [Android Studio](https://developer.android.com/studio) をインストール
2. このリポジトリを clone し、`android-app` フォルダを Android Studio で「Open」
3. 初回はGradle同期が自動で走ります（Android SDK・依存ライブラリを自動取得）
4. 実機（Android）をUSB接続し、USBデバッグを有効にして「Run」
   - Android 12以降は初回起動時に「正確なアラームの許可」「通知の許可」を画面の案内に従って許可してください

### CLIでビルドする場合

```
cd android-app
./gradlew assembleDebug
```

（`ANDROID_HOME` が正しく設定されており、Google のリポジトリに到達できるネットワーク環境が必要です）

## 未実装・今後の検討事項

- 保護者への「未達成が続いた場合の通知」は、サーバーを使わない方針のため見送っています。子ども自身の端末上での表示強化（例：連続未達成日数の表示）は追加可能です。
- 月次CSVの自動メール送信は、Androidの制約上「共有シートを開いて人が送信ボタンを押す」形が現実的な上限です（完全自動送信にはサーバーが必要）。
- アプリアイコンは仮のシンプルな図形です。差し替え可能です。
