# 指数の長期検証スクリプト（円建て）

「米国・日本・全世界のどれに、どんな比率で投資するか」を過去データで確かめるためのスクリプトです。
結果はすべて **円建て**（日本在住の投資家から見た損益）で出します。

## 準備と実行

```bash
pip install -r requirements.txt
python backtest.py              # 長期モード: S&P500 と 日経平均（1971年〜、配当なし）
python backtest.py --mode etf   # ETFモード: SPY / TOPIX ETF(1306) / ACWI（配当込み、2008年〜）
python backtest.py --demo       # ネット接続なしでダミーデータを使って動作確認
```

データは Yahoo Finance（株価）と FRED（ドル円、日米の短期金利）から自動で取得します。

## 出力（`output/` フォルダ）

| ファイル | 見るポイント |
|---|---|
| `1_growth.png` | 1円が何倍になったか。資産と配分ごと |
| `2_rolling_{10,15,20}y.png` | **どの時点で始めても**N年後の年率が何%だったか。始める時期の運の影響がわかる |
| `3_drawdown.png` | 高値からの下落率。耐えられる深さかどうか |
| `4_fx_decomposition.png` | 円建てリターンを「株そのもの」と「為替」に分解 |
| `5_hedged_vs_unhedged.png` | 為替ヘッジ付き（`_H`）と、ヘッジなしの比較 |
| `6_rebalance_sharpe.png` | リバランス方法ごとの「シャープレシオ − 買いっぱなしのシャープレシオ」（N年ローリング）。0より上ならリバランスが効いた期間 |
| `summary.csv` | 年率リターン・リスク・シャープレシオ・最大下落・最長含み損期間・ローリングの最悪/中央/最良/マイナス率 |
| `rebalance_full_period.csv` | 全期間での、リバランス方法ごとのリターン・リスク・シャープ・最大下落・売買回数 |
| `rebalance_rolling.csv` | N年ローリングで、買いっぱなしよりシャープレシオが高かった割合と、差の中央値・最小・最大 |
| `fx_decomposition.csv` | 現地通貨の年率、為替の年率、円建ての年率、それぞれのリスク |

## リバランスの検証

各配分について、次の5つの方法を比べます。

| 方法 | 内容 |
|---|---|
| `none` | 買いっぱなし（比較の基準） |
| `annual` | 毎年12月末に目標比率へ戻す |
| `quarterly` | 3・6・9・12月末に戻す |
| `monthly` | 毎月末に戻す |
| `band` | どれかの資産が目標から `--band`（既定5%ポイント）以上ずれたら戻す |

- シャープレシオ＝（リターン − 円の短期金利）÷ リスク。無リスク金利には FRED の日本3ヶ月金利を使います。
- 全期間の1回だけの比較は偶然に左右されます。そこで開始月を1ヶ月ずつずらした N 年の期間（`--rebalance-window`、既定10年）ごとにも比べ、**何割の開始時点で買いっぱなしに勝てたか**を出します。
- 売買コストは `--cost 0.001`（売買額の0.1%）のように指定できます。

```bash
python backtest.py --cost 0.001 --band 0.10 --rebalance-window 15
```

## カスタマイズ例

```bash
# 期間を変える（例: 日本のバブル天井から始めた場合）
python backtest.py --start 1989-12-01

# 自分の配分を追加する
python backtest.py --mode etf --portfolio "W70JP30=WORLD:0.7,JP:0.3"

# 資産を追加する（名前=ティッカー:通貨）。例: 新興国ETF
python backtest.py --mode etf --asset EM=EEM:USD --portfolio "MIX=WORLD:0.7,JP:0.2,EM:0.1"

# リバランスの方法（annual / monthly / none）、ローリング期間
python backtest.py --rebalance none --windows 5 10 20
```

## 注意（結果を読むときに）

- **長期モードは配当を含みません。** 配当込みにすると年2%前後上乗せになります。日米どちらも除いているので、比較は概ね公平です。
- **ETFモードは期間が短い（2008年〜）** ため、米国が強かった時期の影響を強く受けます。
- **全世界（ACWI）は2008年以降のデータしかありません。** 長期で見られるのは日米の比較だけです。
- **ヘッジ付きは近似です。** 「現地通貨リターン＋（円金利−ドル金利）」で計算しています。実際のファンドはさらにコストがかかります。
- リバランス時の売却にかかる税金（課税口座の場合）は含みません。NISA内なら非課税ですが、売った分の枠が戻るのは翌年です。
- 税金・信託報酬の差・積立（ドルコスト平均法）は考慮していません。一括投資を前提にしています。
- 過去の結果は将来を保証しません。結論はデータを取る期間で大きく変わるので、`--start` を変えて何通りか試してください。
