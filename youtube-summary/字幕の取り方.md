# 字幕の取り方（あなたのパソコンで行う手順）

所要時間：準備 10 分ほど＋自動で待つ時間（80 本で約 30〜60 分）。
動画そのものはダウンロードしません。字幕（文字）だけを取ります。

---

## 1. Python を用意する（入っていない場合だけ）

### Windows
1. https://www.python.org/downloads/ を開き、黄色い「Download Python」ボタンを押す。
2. ダウンロードしたファイルを開く。
3. **最初の画面の下にある「Add python.exe to PATH」に必ずチェック**を入れてから「Install Now」。

### Mac
多くの Mac には最初から入っています。次の手順 3 でエラーになったら、上と同じサイトから入れてください。

---

## 2. スクリプトを保存する

1. `fetch_subs.py` をダウンロードする。
2. デスクトップに「ai-sennin」という名前のフォルダを作り、その中に置く。

---

## 3. 実行する

### Windows
1. 「ai-sennin」フォルダを開く。
2. 上のアドレス欄（フォルダの場所が書いてある所）をクリックし、`cmd` と入力して Enter。黒い画面が開きます。
3. 次を入力して Enter：
   ```
   python fetch_subs.py
   ```

### Mac
1. 「ターミナル」アプリを開く（Launchpad で「ターミナル」と検索）。
2. 次の 2 行を 1 行ずつ入力して Enter：
   ```
   cd ~/Desktop/ai-sennin
   python3 fetch_subs.py
   ```

あとは待つだけです。`[12/80] ... OK` のように進み具合が表示されます。
1 本ごとに 5〜15 秒休むようにしてあるので、ゆっくり進むのが正常です。

---

## 4. 終わったら

- 画面に「この ZIP ファイルを Claude に送ってください」と出ます。
- 同じフォルダにできる **`subs_for_claude.zip`** を、このチャットに添付して送ってください。

## うまくいかないとき

| 表示 | 意味と対処 |
|---|---|
| 「ボット判定で止まりました」 | あなたの回線でも制限がかかりました。数時間〜1日あけて、手順 3 をもう一度実行してください。**取れた分はそのまま残り、続きから再開します。** それまでに取れた分だけ先に送ってもらってもかまいません。 |
| 「エラーで取得できませんでした」 | 一時的な失敗です。最後にもう一度実行すると、その動画だけ取り直します。 |
| `python` が見つからない | Windows は「Add python.exe to PATH」のチェックを忘れた可能性があります。Python をもう一度インストールしてください。 |
